# Рецептура

Приложение для небольших кухонь и домашней проработки рецептов.

- хранит рецепты и ингредиенты по категориям;
- пересчитывает граммовки на выбранное число порций без ошибок `Double`;
- показывает печатную техкарту и открывает системный диалог печати/PDF;
- добавляет пять самостоятельных примеров при первом запуске;
- сбрасывает текущую подборку, не удаляя рецепты.

## Стек и устройство

Kotlin, Jetpack Compose, Material 3, Room/KSP, ViewModel + StateFlow. Пакет разделён на модели и Room (`Data.kt`), состояние (`RecipeViewModel`) и Compose-интерфейс (`MainActivity.kt`). Зависимости создаются вручную в `PortfolioApp`.

## Запуск

Откройте этот каталог в Android Studio или выполните `./gradlew test assembleDebug` с JDK 17 и Android SDK 37.

## Известные ограничения

Редактор создаёт новые рецепты; изменение уже сохранённого рецепта в первой версии не предусмотрено. Системный экран печати зависит от служб печати, установленных на устройстве.
